# Mixed workspace instructions

This fixture has two independent components. For Ledger, read
`components/ledger/AGENTS.md` and `components/ledger/docs/development.md`; for
Beacon, read `components/beacon/AGENTS.md` and
`components/beacon/docs/development.md`. Keep each component's commands and
project facts within its directory. There is no shared runtime, dependency
management, build, test, or deployment configuration.
