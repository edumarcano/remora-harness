# Repository instructions

Follow established project requirements and decisions. Keep observed behavior,
approved intentions, proposals, and unknowns distinct; do not turn an undecided
choice into a project requirement.

Preserve unrelated changes and project-owned guidance. Keep work within the
requested scope and report verification honestly, including checks not run.

Before applying shared guidance, read `.remora/standards/engineering.md` and any
applicable scoped project instructions. Use only workflows that are actually
available in this repository or host.
